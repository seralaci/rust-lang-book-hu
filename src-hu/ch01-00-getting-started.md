# Első lépések {#getting-started}

Kezdjük el a Rust-utazásodat! Sok mindent kell megtanulni, de minden utazás
valahol elkezdődik. Ebben a fejezetben a következőkről lesz szó:

- a Rust telepítése Linuxra, macOS-re és Windowsra
- egy program megírása, amely kiírja, hogy `Hello, world!`
- a `cargo`, a Rust csomagkezelője és buildrendszere használata
